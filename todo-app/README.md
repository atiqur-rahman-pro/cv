# To-Do App — Atiqur Rahman

This small To‑Do application was added to the `atiqur-rahman-pro/cv` repository under the `todo-app/` folder.

Features
- Add tasks with title, due date, priority (Low/Medium/High), and tags.
- Edit, delete, and toggle completion.
- Filter by All / Active / Completed and by tag.
- Sort by created date, due date, or priority.
- Import/Export tasks as JSON.
- Local persistence using localStorage (key: `todoApp.todos.v1`).

Files added
- todo-app/index.html
- todo-app/styles.css
- todo-app/app.js

How to run
1. Open `todo-app/index.html` in a modern browser.
2. Add tasks and they will persist in your browser's localStorage.
3. Use Export to download a JSON backup and Import to restore tasks.

Notes
- This is a client-only app; no server sync is included.
